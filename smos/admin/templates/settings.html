Backup

Downloads the stored documents and the search index as one file. Tokens, invitations and the usage log are not included.

{% if pentest %}Off while pentest mode is on.{% endif %}

Load backup

Replaces everything in the store with the contents of a backup file. SMOS pauses the API briefly, checks the file first, keeps a safety copy of the current store, and puts it back automatically if the loaded store fails its checks.

{% if pentest %}Off while pentest mode is on.{% endif %}

Pentest mode

{% if pentest %}

Pentest mode is on. SMOS is using an empty throwaway store; the live store is untouched. Turning it off deletes the throwaway data and brings the live store back. Tokens and invitations created during the test stay until you remove them on the Access page.

{% else %}

Sets the live store aside and runs SMOS on an empty throwaway store, so API testing cannot touch real data. Existing tokens keep working; create test tokens on the Access page as usual. Turning it off deletes the throwaway store and restores the live one.
